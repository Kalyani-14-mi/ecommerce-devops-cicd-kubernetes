# CI/CD Enabled Microservices Deployment Platform on AWS using Kubernetes
# E-Commerce Application — DevOps CI/CD & Kubernetes Deployment

A hands-on DevOps project demonstrating the containerization, CI/CD
automation, and Kubernetes deployment of a microservices-based
e-commerce application on AWS.

## Project Overview

For this project, I used an existing open-source e-commerce application
as the workload and focused on implementing its DevOps deployment
lifecycle.

The application consists of an Angular frontend and Spring Boot
microservices backend maintained in separate repositories.

My implementation focuses on:

- Jenkins CI/CD automation
- Docker containerization
- Kubernetes orchestration
- AWS EC2 infrastructure
- Application networking
- Deployment and troubleshooting

## Application Repositories

### Frontend

https://github.com/Kalyani-14-mi/ecommerce-frontend-web-app

### Backend

## Technology Stack

| Category | Technology |

| Cloud | AWS |
| CI/CD | Jenkins |
| Containerization | Docker |
| Orchestration | Kubernetes |
| Version Control | Git & GitHub |
| Backend | Java, Spring Boot, Maven |
| Frontend | Angular |
| Operating System | Linux |

## CI/CD Workflow

The high-level deployment workflow is:

GitHub → Jenkins → Build → Docker Image → Kubernetes → AWS

## DevOps Implementation

This project demonstrates:

- Automated application builds using Jenkins
- Docker image creation
- Kubernetes-based application deployment
- Frontend and backend deployment
- Kubernetes service networking
- Deployment on AWS infrastructure
- Linux and Kubernetes troubleshooting
